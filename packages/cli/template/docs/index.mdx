# Welcome to your docs

This is your first documentation page. Edit or add new `.mdx` files in the
`docs/` directory to build your documentation.

## Getting Started

Versio turns Markdown into fast, searchable, versioned documentation sites.
Start by editing this file or creating new ones.

### Features

- **Full-text search** — offline-first, typo-tolerant
- **Versioned docs** — ship multiple versions without duplication
- **Custom MDX components** — tabs, API tables, callouts, and more
- **Dark mode** — automatic theme switching
- **Auto table of contents** — scroll-spying sidebar
