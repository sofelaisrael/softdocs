# Getting Started

Add SoftDocs to your project with a single command.

## Installation

Run the following in your terminal:

```bash
npm create softdocs@latest my-docs
```

Then navigate into the project:

```bash
cd my-docs && npm run dev
```

## Configuration

Create a `softdocs.config.ts` file:

```typescript
import { defineConfig } from 'softdocs'

export default defineConfig({
  title: 'My Docs',
  description: 'Documentation for my project',
  theme: {
    accent: '#6366f1'
  }
})
```
