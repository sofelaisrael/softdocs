Add SoftDocs to your project with a single command. The CLI scaffolds a complete documentation site with sensible defaults — zero-config search, version routing, and theme compilation.

## Quick start

Run the following in your terminal to create a new documentation site:

```bash
# Create a new documentation site
npm create softdocs@latest my-docs

# Navigate into the project
cd my-docs

# Start the dev server
npm run dev
```

That's it. Open `http://localhost:3000` and you will see your documentation site running with the default theme, search indexing, and version routing already configured.

> **Prerequisites:** Node.js 18+ and npm 9+. SoftDocs works with any package manager — npm, yarn, pnpm, bun.

## Manual setup

If you prefer to add SoftDocs to an existing project, install the package directly:

```bash
# Install the package
npm install softdocs

# Initialize in your project
npx softdocs init
```

The `init` command creates a `softdocs.config.ts` file in your project root and a `docs/` directory with a sample document. You can configure everything from the config file:

```typescript
import { defineConfig } from 'softdocs'

export default defineConfig({
  title: 'My Docs',
  description: 'Documentation for my project',
  theme: {
    accent: '#3b82f6'
  }
})
```

## Directory structure

After initialization, your project looks like this:

```
my-docs/
├── docs/
│   ├── getting-started/
│   │   ├── installation.md
│   │   ├── configuration.md
│   │   └── first-document.md
│   ├── guides/
│   │   ├── custom-mdx.md
│   │   └── versioning.md
│   └── index.md
├── public/
│   └── logo.svg
├── softdocs.config.ts
├── package.json
└── README.md
```

Markdown files under `docs/` are automatically mapped to routes. The directory structure becomes your URL structure — no manual routing needed.

## Writing your first document

Create a file at `docs/getting-started/overview.md`:

```markdown
---
title: Overview
description: What SoftDocs does and how it works
version: [">=2.0"]
---

# Overview

SoftDocs is a documentation platform that turns Markdown into fast, searchable sites.

## How it works

1. Write content in Markdown or MDX
2. Configure your theme and version options
3. Deploy anywhere — Vercel, Netlify, or static export

> SoftDocs handles search indexing, version routing, and theme compilation automatically.
```

The frontmatter block at the top controls metadata: title, description, version range, and more. SoftDocs uses this to generate the table of contents, search index, and version diff highlighting.

> **Tip:** Use the `version` field to control which versions of your docs a page belongs to. SoftDocs automatically filters pages by version — no duplicate files needed.

## Troubleshooting

> **Port already in use?** Run `npm run dev -- --port 3001` or set `PORT=3001` in your environment.

See the full [CLI reference](#) for all available commands and flags.

---

| Command | Description |
|---------|-------------|
| `npm create softdocs@latest` | Scaffold a new documentation site |
| `npx softdocs init` | Add SoftDocs to an existing project |
| `npm run dev` | Start the development server |
| `npm run build` | Build for production (static export) |
| `npx softdocs version` | Create a new version snapshot |
