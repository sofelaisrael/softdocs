# Getting Started

Add Versio to your project with a single command.

## Installation

Run the following in your terminal:

```bash
npm create versio@latest my-docs
```

Then navigate into the project:

```bash
cd my-docs && npm run dev
```

## Configuration

Create a `versio.config.ts` file:

```typescript
import { defineConfig } from "@sofelaisrael/core";

export default defineConfig({
  title: "My Docs",
  description: "Documentation for my project",
  theme: {
    accent: "#6366f1",
  },
});
```
