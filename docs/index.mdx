# Overview

Welcome to SoftDocs. This is the beginning of your documentation.

## What is SoftDocs?

SoftDocs is a documentation platform that turns Markdown into fast, searchable sites.

## How it works

1. Write content in Markdown or MDX
2. Configure your theme and version options
3. Deploy anywhere

### Key Features

- Full-text search
- Versioned docs
- Custom MDX components
- Dark mode
